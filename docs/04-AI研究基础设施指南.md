## 1. 任务一：利用 GPT Plus/Pro 进行科学研究

### 1.1 套餐选择

| 套餐 | 月费 | Deep Research 配额 | 适用人群 |
|------|------|---------------------|----------|
| Free | $0 | 5 次/月 | 仅尝鲜 |
| Plus | $20 | 10 次/月 | 偶尔做文献调研 |
| Pro $100 | $100 | ≈ 50 次/月 | 中度研究者 |
| **Pro $200** | **$200** | **几乎无限** + GPT-5.5 Pro | **科研主力** |

### 1.2 科研核心工作流：Deep Research

2026 年 2 月起，Deep Research 已切换到 GPT-5.2 模型，支持 MCP / Google Drive / SharePoint / Dropbox 等连接器。

**典型场景**：
1. **文献综述**：上传 PDF → 让 Deep Research 系统综述
2. **竞争情报**：调研行业头部公司的最新动态
3. **数据二次分析**：上传 CSV → 跑描述性统计
4. **政策 / 法规解读**：限定可信源（gov.cn / lawtime.cn）

**关键限制**：
- 单次 5-30 分钟，不适合即时问答
- 引用 hallucination 率 18-55%（法律领域 58-88%）→ **所有引用必须人工复核**
- 输出可下载为 Markdown / Word / PDF

### 1.3 提示词模板

**文献综述**：
```
你是 XX 领域的研究者。请围绕"XXX"主题，系统综述近 5 年高被引文献
与最新进展，按"研究背景→主要流派→核心争议→未来方向"组织，
每条结论给出可追溯的引用。
```

**竞争情报**：
```
请调研 XXX 行业 2024-2026 年头部 5 家公司的产品矩阵、定价策略、
最新融资动态，输出一份带引用链接的对比表格。
```

### 2.2 关键命令

```bash
# 系统更新
apt update && apt upgrade -y

# 启用 BBR
echo "net.core.default_qdisc=fq" >> /etc/sysctl.conf
echo "net.ipv4.tcp_congestion_control=bbr" >> /etc/sysctl.conf
sysctl -p

# 防火墙
ufw allow 22/tcp && ufw allow 443/tcp && ufw enable

# 一键部署 Reality
bash <(curl -Ls https://raw.githubusercontent.com/fscarmen/sing-box/main/sing-box.sh)
```

## 3. 任务三：聚合 Dashboard（New-API）

### 3.1 选型

| 方案 | 推荐度 | 许可证 |
|------|--------|--------|
| **New-API** ⭐ | 首选（One-API 继任者） | AGPL-3.0（个人自用无影响） |
| One-API | 不推荐（停止维护） | MIT |
| LiteLLM | Python 生态友好 | MIT |
| 商业（OpenRouter / Helicone）| 数据出境风险 | 闭源 |

### 3.2 Docker Compose 部署

```yaml
# docker-compose.yml
version: '3.8'
services:
  new-api:
    image: calciumion/new-api:latest
    container_name: new-api
    restart: always
    ports:
      - "3000:3000"
    volumes:
      - ./data:/data
    environment:
      - SQL_DSN=root:123456@tcp:db:3306/new-api
      - REDIS_CONN=redis://redis:6379
      - TZ=Asia/Shanghai
      - GENERATE_DEFAULT_TOKEN=false

  db:
    image: mysql:8.0
    container_name: new-api-db
    restart: always
    environment:
      MYSQL_ROOT_PASSWORD: 123456
      MYSQL_DATABASE: new-api
    volumes:
      - ./mysql:/var/lib/mysql

  redis:
    image: redis:7-alpine
    container_name: new-api-redis
    restart: always
```

启动：
```bash
docker compose up -d
```

访问 `http://VPS_IP:3000`，默认账号 `root` / `123456`（**首次登录立即修改！**）

## 5. 风险与合规

### 5.1 法律与合规

- 大陆地区：自建 VPS 处于灰色地带，遵守单位 IT 政策
- 学术诚信：Deep Research 引用 hallucination 率高，必须人工复核
- 数据出境：敏感数据走国内渠道（DeepSeek / Qwen / GLM）
- AGPL-3.0：New-API 个人自用无影响，二次分发需谨慎

### 5.2 隐私保护

- 不在 Deep Research 提示词中放未加密的敏感个人信息
- OpenAI Settings → Data Controls → 关闭"Improve model for everyone"
- Claude / GPT 默认不训练，可放心使用
