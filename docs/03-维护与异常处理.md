## 二、定期维护（每月 1 次，30 min）

### 2.1 更新系统

```bash
# 在 Tabby 连接 VPS 的窗口中
sudo apt update && sudo apt upgrade -y
```

### 2.2 更新 sing-box

```bash
# 一键更新（脚本会处理）
bash <(curl -Ls https://raw.githubusercontent.com/fscarmen/sing-box/main/sing-box.sh)
```

脚本自动检测版本、更新二进制、重启服务。

### 2.3 检查 SSH 异常登录

```bash
sudo journalctl -u ssh --since "1 month ago" | grep -i fail
```

**正常**：零星几次失败（来自全球扫描）
**异常**：某个 IP 大量失败 → 拉黑该 IP：
```bash
sudo ufw deny from <异常IP>
```

### 2.4 备份配置

```bash
# 手动备份
scp root@你的VPS:/etc/sing-box/config.json ~/Desktop/

# 或用脚本（推荐）
bash scripts/backup-config.sh
```

### 2.5 清理磁盘日志

```bash
sudo journalctl --vacuum-time=30d
```

## 三、异常处理预案

### 3.1 故障树速查

| 现象 | 可能原因 | 解决方法 | 耗时 |
|------|---------|---------|------|
| **突然连不上** | IP 被墙 / 欠费 / 系统崩溃 | `ping` IP → 不通就销毁重建 | 5 min |
| **速度突然变慢** | 晚高峰拥塞 / 机房问题 | 换机房 / 升级配置 | 30 min |
| **能上 Google 但不能上 ChatGPT** | IP 被 OpenAI 拉黑 | 销毁 VPS 换 IP | 5 min |
| **SSH 也连不上** | IP 被墙 / 防火墙配置错 | 用 Vultr 控制台 VNC 进 → 修防火墙 | 30 min |
| **Clash 显示连接但不能上网** | 配置错误 / 节点失效 | 重新导入节点链接 | 2 min |
| **DNS 泄漏** | Clash DNS 配置错 | 启用 fake-ip 模式 + 配 nameserver-policy | 10 min |

### 3.2 IP 被墙的完整流程

**判断**：
```bash
# 在本地 Windows PowerShell
ping 你的VPS_IP
```

如果 ping 不通（超时）= 大概率被墙。

**解决**（Vultr 后台）：
1. Products → 选中服务器 → **Destroy**（销毁）
2. 立即 **Deploy New Server**（新服务器）
3. 选**同一个机房**（保持延迟一致）
4. 重新跑部署脚本
5. 客户端更新节点链接

**总耗时**：5-10 分钟

### 3.3 端口被封的应急

**症状**：SSH 正常，但代理连不上

**解决**：
```bash
# 1. 换端口（修改 sing-box 配置）
nano /etc/sing-box/config.json
# 把 listen_port 从 443 改成 2053 或 8443
systemctl restart sing-box

# 2. 同步更新防火墙
ufw allow 2053/tcp
ufw delete allow 443/tcp

# 3. 客户端同步更新端口
```

### 3.4 VPS 被入侵

**症状**：
- 收到 fail2ban 大量告警
- 流量异常飙升
- 系统负载异常

**应急**：
1. 立即销毁 VPS（Vultr 后台）
2. 用上一个干净的快照/重建
3. 检查本地是否有密钥泄露
4. **永远不要花超过 30 分钟修复被入侵的 VPS**

## 四、监控建议

### 4.1 UptimeRobot 免费监控（推荐）

1. 注册 https://uptimerobot.com/（免费）
2. Add New Monitor → Ping
3. 填入 VPS IP
4. 设置告警邮箱 / 微信
5. VPS 挂掉时立即通知

### 4.2 流量监控

Vultr 后台 → Server → **Bandwidth** 可以看到实时流量。

### 4.3 简单巡检脚本

保存为 `scripts/health-check.sh`：
```bash
#!/bin/bash
echo "=== VPS 健康检查 ==="
echo "1. 系统时间: $(date)"
echo "2. 运行时长: $(uptime -p)"
echo "3. 磁盘使用: $(df -h / | tail -1 | awk '{print $5}')"
echo "4. 内存使用: $(free -m | grep Mem | awk '{print $3"/"$2"MB"}')"
echo "5. sing-box 状态: $(systemctl is-active sing-box)"
echo "6. 443 端口监听: $(ss -tlnp | grep -c ':443')"
echo "7. 最近失败登录: $(journalctl -u ssh --since '7 days ago' | grep -c -i fail)"
```

每周跑一次：
```bash
bash scripts/health-check.sh
```

## 六、备份策略

### 6.1 手动备份

```bash
# 备份 sing-box 配置
scp root@VPS_IP:/etc/sing-box/config.json ./backups/

# 备份整个项目
scp -r root@VPS_IP:/etc/sing-box/ ./backups/sing-box-$(date +%Y%m%d)/
```

### 6.2 自动备份（推荐）

```bash
# 添加到 crontab（每天凌晨 3 点备份）
crontab -e
# 加一行：
0 3 * * * /root/scripts/backup-config.sh
```

详见 `scripts/backup-config.sh`。

### 6.3 备份存储位置

| 位置 | 优点 | 缺点 |
|------|------|------|
| 本地电脑 | 访问快 | 单点故障 |
| GitHub 私有仓 | 版本管理 + 异地备份 | 公网存储敏感信息风险 |
| 加密 U 盘 | 安全 | 手动同步 |
| 加密云盘（坚果云等）| 异地 + 自动同步 | 国内访问稳定 |

**推荐**：本地 + 加密云盘双备份。
