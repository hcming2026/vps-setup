# 多协议实战指南

> Reality + Hysteria2 + AnyTLS 双协议 / 多协议实战
> 适用：单 Reality 不够用、需要冗余备份时

---

## 一、为什么要多协议？

Reality 已经足够强，但仍然有局限：

| 场景 | Reality 表现 | 原因 |
|------|-------------|------|
| 日常网页 | ✅ 完美 | TCP TLS 1.3 |
| 视频会议（Zoom 等）| ⚠️ 偶尔卡 | UDP 流量被 QoS |
| 大文件下载 | ⚠️ 中等速度 | TCP 单连接拥塞 |
| 晚高峰 | ⚠️ 拥塞 | TCP QoS 限速 |

**Hysteria 2 补 Reality 的短板**：基于 QUIC（UDP），抗 TCP QoS，速度快 2-3 倍。

---

## 二、协议组合策略

### 推荐组合

| 协议 | 端口 | 作用 |
|------|------|------|
| **VLESS+Reality** | 443 | 主力 TCP 节点 |
| **Hysteria 2** | 8443 | UDP 加速 / TCP 受限备份 |
| **VLESS+WS+TLS+CDN** | 2053 | 兜底（IP 被墙时用）|

### 客户端策略

| 客户端 | 自动选择 |
|--------|---------|
| 默认 | Reality（稳定）|
| 看视频 / 大文件 | Hysteria 2（快）|
| IP 被墙 | WS+TLS+CDN |

## 三、Reality + Hysteria 2 同实例部署

### 3.1 前提条件

- ✅ 已有 Reality 节点跑通
- ✅ 有域名（用于 Hysteria 2 的 ACME 自动证书）
- ✅ 域名 A 记录指向 VPS IP

### 3.2 完整 sing-box 配置

`/etc/sing-box/config.json`：

```json
{
  "log": { "level": "info" },
  "inbounds": [
    {
      "type": "vless",
      "tag": "vless-reality-in",
      "listen": "::",
      "listen_port": 443,
      "users": [
        {
          "uuid": "你的UUID-同一个",
          "flow": "xtls-rprx-vision"
        }
      ],
      "tls": {
        "enabled": true,
        "server_name": "www.apple.com",
        "reality": {
          "enabled": true,
          "handshake": {
            "server": "www.apple.com",
            "server_port": 443
          },
          "private_key": "你的REALITY私钥",
          "short_id": ["你的短ID"]
        }
      }
    },
    {
      "type": "hysteria2",
      "tag": "hy2-in",
      "listen": "::",
      "listen_port": 8443,
      "up_mbps": 100,
      "down_mbps": 100,
      "users": [
        {
          "password": "你的强密码"
        }
      ],
      "tls": {
        "enabled": true,
        "acme": {
          "domain": "hy2.yourdomain.com",
          "email": "your@email.com"
        }
      },
      "masquerade": "https://www.bing.com"
    }
  ],
  "outbounds": [
    { "type": "direct", "tag": "direct" }
  ]
}
```

### 3.3 重启服务

```bash
# 验证配置
sing-box check -c /etc/sing-box/config.json

# 重启
systemctl restart sing-box

# 查看日志
journalctl -u sing-box -f --since "1 minute ago"
```

### 3.4 防火墙

```bash
ufw allow 8443/udp
ufw allow 8443/tcp
```

## 四、客户端配置

### 4.1 Clash Verge Rev 配置

```yaml
proxies:
  # Reality 节点（TCP 主力）
  - name: "VPS-Reality"
    type: vless
    server: 你的VPS_IP
    port: 443
    uuid: 你的UUID
    flow: xtls-rprx-vision
    tls: true
    servername: www.apple.com
    reality-opts:
      public-key: 你的REALITY公钥
      short-id: 你的短ID

  # Hysteria 2 节点（UDP 加速）
  - name: "VPS-Hysteria2"
    type: hysteria2
    server: hy2.yourdomain.com
    port: 8443
    password: 你的强密码
    sni: hy2.yourdomain.com

proxy-groups:
  - name: "🚀 节点选择"
    type: select
    proxies:
      - VPS-Reality
      - VPS-Hysteria2
      - DIRECT

  - name: "⚡ 自动选择（按延迟）"
    type: url-test
    url: "http://www.gstatic.com/generate_204"
    interval: 300
    tolerance: 50
    proxies:
      - VPS-Reality
      - VPS-Hysteria2
```

## 五、AnyTLS（sing-box 1.12+ 新协议）

### 5.1 特点

- 轻量级 TCP/TLS 协议
- 比 Reality 简单，比 Trojan 抗检测
- **观察期协议**：2026 年仍需观察 GFW 是否能识别

### 5.2 配置

```json
{
  "type": "anytls",
  "tag": "anytls-in",
  "listen": "::",
  "listen_port": 9443,
  "users": [
    {
      "name": "yourname",
      "password": "你的AnyTLS密码"
    }
  ],
  "tls": {
    "enabled": true,
    "acme": {
      "domain": "anytls.yourdomain.com",
      "email": "your@email.com"
    }
  }
}
```

### 5.3 推荐策略

- **不作主力**：观察 GFW 反应
- **作备用节点**：3 个 Reality + 1 个 AnyTLS 测试

## 七、性能优化

### 7.1 Hysteria 2 带宽设置

根据 VPS 实际带宽调整：

```json
"up_mbps": 100,      // VPS 上传带宽
"down_mbps": 1000     // VPS 下载带宽（家用宽带下行大）
```

测试 VPS 实际带宽：

```bash
curl -s https://raw.githubusercontent.com/sivel/speedtest-cli/master/speedtest.py | python3
```

### 7.2 Reality TCP Buffer 优化

```json
{
  "tcp_fast_open": true,
  "tcp_multi_path": true
}
```

加到 sing-box 全局配置。

### 7.3 BBR 拥塞控制

```bash
echo "net.core.default_qdisc=fq" >> /etc/sysctl.conf
echo "net.ipv4.tcp_congestion_control=bbr" >> /etc/sysctl.conf
sysctl -p
lsmod | grep bbr  # 验证
```

## 八、监控多协议节点

### 8.1 sing-box 状态查询

```bash
# 查看 inbounds 监听
ss -tlnp | grep sing-box

# 查看 inbounds 监听（UDP）
ss -ulnp | grep sing-box
```

### 8.2 节点健康检查脚本

```bash
#!/bin/bash
# 定期检查 Reality 和 Hy2 是否在线

check_reality() {
    nc -zv 你的VPS_IP 443 2>&1 | grep -q "open"
    [ $? -eq 0 ] && echo "✅ Reality: online" || echo "❌ Reality: offline"
}

check_hy2() {
    nc -zuv hy2.yourdomain.com 8443 2>&1 | grep -q "open"
    [ $? -eq 0 ] && echo "✅ Hysteria2: online" || echo "❌ Hysteria2: offline"
}

check_reality
check_hy2
```

加入 crontab 每 5 分钟跑一次：

```bash
*/5 * * * * /root/scripts/check-nodes.sh >> /var/log/node-status.log
```

## 九、CDN 兜底：VLESS+WS+TLS+Cloudflare

### 9.1 适用场景

- VPS IP 被墙（GFW 阻断）
- 仍想继续访问外网
- 不在乎速度损失 10-30%

### 9.2 部署架构

```
Client → Cloudflare CDN（边缘节点）→ VPS 真实 IP → sing-box
```

Cloudflare CDN 看到的是"普通 HTTPS 流量"，GFW 无法封禁。

### 9.3 完整部署

#### 9.3.1 VPS 端 Nginx 反代

`/etc/nginx/conf.d/vless-ws.conf`：

```nginx
server {
    listen 443 ssl;
    server_name proxy.yourdomain.com;
    ssl_certificate /etc/letsencrypt/live/proxy.yourdomain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/proxy.yourdomain.com/privkey.pem;

    location / {
        root /var/www/html;
    }

    location /你的随机路径/ {
        proxy_redirect off;
        proxy_pass http://127.0.0.1:10086;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
    }
}
```

#### 9.3.2 sing-box 配置 WS 入口

```json
{
  "inbounds": [
    {
      "type": "vless",
      "tag": "vless-ws-in",
      "listen": "127.0.0.1",
      "listen_port": 10086,
      "users": [
        { "uuid": "你的UUID" }
      ],
      "transport": {
        "type": "ws",
        "path": "/你的随机路径/"
      }
    }
  ]
}
```

#### 9.3.3 Cloudflare 配置

1. 域名解析到 VPS IP，**橙色云朵**（启用 CDN）
2. SSL/TLS → **Full** 模式
3. Network → 启用 **WebSocket**
4. Cloudflare 端口：用 443 / 2053 / 2083 / 2087 / 2096 / 8443

#### 9.3.4 客户端配置

```yaml
- name: "VPS-WS-CDN"
  type: vless
  server: proxy.yourdomain.com
  port: 443
  uuid: 你的UUID
  tls: true
  servername: proxy.yourdomain.com
  network: ws
  ws-opts:
    path: /你的随机路径/
```

## 十、协议选型决策树

```
你现在的需求是什么？
│
├── 日常网页浏览
│   └── VLESS+Reality ✅（推荐）
│
├── 看 YouTube / 大文件下载
│   └── Hysteria 2 ✅（速度优先）
│
├── 视频会议（Zoom/Meet）
│   └── Hysteria 2 ✅（UDP 友好）
│
├── IP 被墙
│   └── VLESS+WS+TLS+CF ✅（兜底）
│
├── 追求极致抗检测
│   └── Reality + CD 域名 ✅
│
└── 不确定
    └── 先跑 Reality → 跑通后再加 Hy2
```

## 十一、推荐演进路线

```
Day 1:  Reality 单节点跑通
   ↓
Week 2: IP 被封一次（正常）
   ↓ 重建 VPS
Week 3: 加 Hysteria 2 备用
   ↓
Month 2: 买域名 + 套 CF CDN（兜底）
   ↓
Month 6: 多机房备份（东京 + 新加坡）
```

**原则**：永远不要一次性把方案搞太复杂。**先跑通，再演进**。
