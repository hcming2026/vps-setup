## 一、先理解网络环境的本质问题

GFW（Great Firewall）会对**出境流量做特征检测**：
- 检测到 VMESS / Trojan / SS-2018 等老协议特征 → 阻断 IP
- 检测到大量加密流量异常 → 限制速度
- 检测到数据中心 IP 集中访问特定域名 → 标记可疑

**科学上网的本质**：让你的出境流量"看起来像普通 HTTPS 流量"，骗过特征检测。

| 方案 | 谁拥有服务器 | 谁搭建 | 风险承担者 | 月费 | 推荐场景 |

**科研用户推荐自建的核心理由**：

3. **长期**：一次投入，每月只付 VPS 费用
4. **可演进**：从单节点升级到多协议 + CDN 都自己掌控

## 三、为什么 2026 年必须用 VLESS+Reality？

### 3.1 协议抗检测能力对比

| 协议 | 抗检测 | 速度 | 推荐度 |
|------|--------|------|--------|
| **VLESS+Reality** | ★★★★★ | 中-高 | **P0 主力** |
| Hysteria 2 | ★★★★ | 极高（QUIC）| P1 备用加速 |
| AnyTLS（sing-box 1.12+）| ★★★★ | 中 | P1 新协议观察 |
| VLESS+WS+TLS+CDN | ★★★ | 中 | P2 兜底（需域名） |
| Shadowsocks-2022 | ★★★ | 中 | P3 兜底 |
| Trojan | ★★★ | 中 | P3 存量兼容 |
| VMESS / V2Ray | ★★ | 中 | **P4 不建议新建** |

### 3.2 Reality 的核心原理

**传统代理的漏洞**：GFW 可以主动探测服务器端口，发现"响应不像普通 HTTPS" → 封 IP。

**Reality 的精髓**：
- 在 TLS 握手阶段，**让 GFW 看到的就是一个普通的 HTTPS 流量**
- 不真的去访问目标网站（如 apple.com），而是**伪装成**在访问
- 即使被主动探测，也能正确响应 → 通过检测

**结论**：Reality 是当前唯一长期稳定的抗检测方案。

## 五、为什么不用朋友的电脑？

| 维度 | VPS | 朋友家用电脑 |
|------|-----|------------|
| 月费 | $4-6 | 0（但有电费） |
| 上行带宽 | 1Gbps | **10-50Mbps（致命短板）** |
| IP 类型 | 数据中心 IP | **住宅 IP（更难封）** |
| 24h 在线 | ✅ | ❌（朋友要关机） |
| 依赖 | 无 | 强（朋友必须愿意配合） |

**结论**：
- 朋友电脑**技术上可行**，但**运行时间不稳定 + 上行带宽低 + 强依赖**
- 真正的折中方案：让朋友买一台 **N100 迷你主机**（¥600，10W 功耗），但增加了协调成本
- **个人长期科研用户首选还是 VPS**
